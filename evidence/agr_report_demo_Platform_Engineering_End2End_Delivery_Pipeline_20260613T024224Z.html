FAIL (CRITICAL): Three Tier-1 build tool integrity issues detected.

No cosign verification of the builder image. SolarWinds-class risk — a compromised build environment injects malicious code that no downstream scanner can detect because the binary is clean by checksum but the tool that produced it was compromised.

2. AI_Verify step in Deploy_to_Prod uses image shubhendupatidar/ai-verify-plugin:4.0 — floating semver tag, no digest pin. This is a Tier-1 tool that runs in the production deployment stage.

3. HarnessSCA_1 container scan uses tag: latest for the target image reference — while this is the scan target rather than the scanner tool itself, it indicates floating reference hygiene issues.

Fix: Pin BuildAndPushDockerRegistry builder to a verified digest. Replace shubhendupatidar/ai-verify-plugin:4.0 with shubhendupatidar/ai-verify-plugin@sha256:<digest> and add cosign verification. Policy: build_tool_integrity.rego
